

# Escopo do Sistema



O OpenRoute tem como escopo auxiliar o planejamento e a organização de operações de entrega que envolvem múltiplos destinos, oferecendo recursos para gerenciamento de informações e otimização de trajetos.



## Funcionalidades contempladas



O sistema contempla as seguintes áreas funcionais:



- **Autenticação e controle de acesso:** gerenciamento do acesso à plataforma por meio dos perfis ADM e USUARIO.

- **Gerenciamento de usuários:** cadastro, consulta, listagem e desativação de contas de usuários, conforme as permissões administrativas.

- **Gerenciamento de destinos e informações de entrega:** organização dos dados necessários ao planejamento das operações.

- **Otimização de rotas:** cálculo de trajetos e definição de uma sequência de atendimento considerando os dados e as restrições operacionais disponíveis.

- **Visualização de rotas:** apresentação dos trajetos em mapas para apoiar a execução das entregas.



## Perfis de acesso



O sistema possui dois perfis:



- **ADM:** responsável pelas operações administrativas, incluindo o gerenciamento de contas de usuários.

- **USUARIO:** perfil operacional utilizado pelo motorista para acessar os recursos relacionados à execução das entregas.



## Limites do sistema



O OpenRoute não substitui a execução física das entregas. Sua finalidade é apoiar o planejamento e a organização dos trajetos.



A plataforma também depende de serviços externos para determinadas operações, como geocodificação de endereços e obtenção de informações de rotas.



As funcionalidades efetivamente disponíveis dependem da implementação existente no frontend e no backend do projeto.
